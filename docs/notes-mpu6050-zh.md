# MPU6050实现与单位说明（修复后）

- 硬件I2C2 PB10/PB11，AD0接地，HAL地址为0x68<<1。
- WHO_AM_I必须为0x68；上层在失败后冷却重试，不能只根据读取返回HAL_OK就认定初始化完成。
- PWR_MGMT_1=1，CONFIG=6，SMPLRT_DIV=9，GYRO_CONFIG=0，ACCEL_CONFIG=0：内部100 Hz，陀螺DLPF约5 Hz，±250°/s、±2g。App每100 ms读取，不是DMA。
- 从0x3B一次读取14字节，大端有符号16位。GX先解释符号，再以int32减偏置，最后饱和到int16，避免边界回绕；不把绝对值>30000的合法大数据置零。
- 初始化后等待100 ms，200个静止样本间隔至少10 ms，增量校准约2秒或更长，不阻塞完成整个校准。每轴样本跨度>500计数时拒绝本轮；均匀旋转仍可能被误当偏置，所以必须人工保持静止。
- 只有完整配置、校准、读取成功后数据才有效。失败取消FSM的待确认，并使对应八点滤波窗口失效。恢复后重新配置和校准，期间显示INVALID。
- 加速度转换：raw×100/16384，为放大100倍的g；角速度raw×100/131，为放大100倍的°/s；统一打印两位小数。例如GX=-4897约-37.38°/s，不是-373.8°/s。
- OLED标注raw的值保持原始计数；运动阈值2000/1000也在原始计数域，只有X轴角速度用于判断，不是角度、位移或全方向运动检测。
- 八点滑动平均预热期用有效样本数作分母，满窗维护环形滑动和。累加器使用int64，支持全int32输入范围；滤波可主机测试。

历史演示中的单位错误数字不再作为硬件性能证据。零偏、温漂、运动恢复和DLPF实际效果仍须板上验证。
